  - Signaux I2C (SDA, SCL) de J3 vers R2a/R2b vers U1
  - Connexions entre composants SMD
  - Éviter angles 90° (préférer 45°)

FACE ARRIÈRE (B.Cu) :
  - Pistes VBAT : J2 → SW4 → U3 (piste alimentation 0.5mm)
  - Retours GND locaux
  - Connexions boutons → vias → U1 (face avant)
  - Pistes verticales (axe Y) si besoin

VIAS (Changement couche) :
  - Utiliser pour GND (connexion plan masse)
  - Éviter sur pistes signaux (augmente impédance)
  - Placer hors zone SMD (accès fer à souder)

PRIORITÉS ROUTAGE :
  1. Alimentation (+3.3V, VBAT, GND)
  2. Bus I2C (SDA, SCL) — Longueurs courtes (U1 ↔ J3 ~12mm)
  3. Signaux critiques (PD3 PWM LED, RESET)
  4. Signaux boutons (PD2, PD4, PB0)
